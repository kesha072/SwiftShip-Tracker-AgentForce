# SwiftShip Tracker – AgentForce

## Project Overview
SwiftShip Tracker is an AI-powered parcel tracking prototype developed using Salesforce AgentForce and Agent Builder.

The Parcel Tracking Agent understands parcel-related queries, executes the required Salesforce Flow, retrieves information from Salesforce custom objects, and provides an appropriate response.

## Objectives
- Implement an AI-powered Parcel Tracking Agent
- Recognize parcel-related user queries
- Execute appropriate Salesforce Flows
- Retrieve data from Salesforce custom objects
- Validate Agent interactions within a Salesforce Developer Org
- Document testing, maintenance, and troubleshooting

## Technologies Used
- Salesforce
- AgentForce
- Agent Builder
- Salesforce Flows
- Salesforce Custom Objects
- AI-powered Service Agent

## Custom Objects
- **Parcel** – parcel and tracking information
- **Customer** – customer information
- **Delivery** – delivery information and status

## Agent Workflow
User Query → Parcel Tracking Agent → Topic Recognition → Flow Execution → Salesforce Custom Objects → Data Retrieval → Agent Response

## Testing
Testing was conducted within the Salesforce Developer Org to validate topic recognition, Flow execution, Salesforce data retrieval, custom object access, Agent responses, permissions, and configuration.

Real-world production testing such as UAT or sandbox deployment was not performed because this project was implemented in a Salesforce Developer Edition environment. Enterprise-level sandbox testing, staging environments, and CI/CD automation are outside the scope of this academic prototype.

## Maintenance & Monitoring
Monitoring includes incorrect topic recognition, failed Flow executions, incorrect data retrieval, permission-related issues, performance delays, and incorrect Agent responses.
